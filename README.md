Что делает программа

1. Загружает список городов из `cities.txt`.
2. Удаляет повторяющиеся города.
3. Для каждого города получает текущую погоду через `wttr.in`.
4. Создаёт объект `WeatherData` с полями:
   - город;
   - текущая температура в °C;
   - страна.
5. Выводит информацию по каждому городу.
6. Группирует города по странам.
7. Для каждой страны вычисляет:
   - количество городов;
   - среднюю температуру;
   - минимальную температуру;
   - максимальную температуру.

Ограничения

Внешние Python-пакеты не используются.
Используются только стандартные модули:
- `json`
- `urllib.parse`
- `urllib.request`
 Запуск
Нужен Python 3.
В терминале откройте папку проекта и выполните:
    python3 main.py

Для работы программы нужен интернет.
